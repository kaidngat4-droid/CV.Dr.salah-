## 🚀 طريقة الاستخدام / How to Use

### 1. فتح الملف
افتح `index.html` في أي متصفح حديث (Chrome, Firefox, Edge, Safari)

### 2. إضافة الصور
ضع صورك في مجلد `images/` بالأسماء التالية:
| اسم الملف | الاستخدام |
|-----------|-----------|
| `profile.jpg` | صورتك الشخصية |
| `first-aid.jpg` | دليل الإسعافات |
| `asset-app.jpg` | تطبيق الأصول |
| `nias-website.jpg` | موقع NIAS |
| `cardio-system.jpg` | نظام القلب |
| `health-reports.jpg` | التقارير الصحية |
| `inventory.jpg` | الجرد الإلكتروني |
| `quran-app.jpg` | تطبيق القرآن |
| `estsharion.jpg` | منصة استشاريون |

> **ملاحظة**: إذا لم توجد الصور، ستختفي تلقائياً دون تأثير على التصميم.

### 3. التبديل بين اللغات
اضغط على زر **English / العربية** أعلى الصفحة

### 4. الطباعة
اضغط على زر "طباعة السيرة" أو استخدم `Ctrl+P`
